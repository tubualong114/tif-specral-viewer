# QuPath 像素光谱查看器

面向 **QuPath 0.7.0** 的开源扩展，用于浏览多通道图像、读取像素原始光谱、计算多点平均光谱并导出数据。

[English documentation](README_en.md)

## 功能

- 通道滑条：`0` 显示全部直接通道，`1…N` 显示指定单通道。
- 光谱探针：启用后在主图像中单击像素，读取当前 Z/T 平面的全部原始通道值。
- 非模态光谱窗口：显示坐标、像素类型、光谱曲线和逐通道数据表。
- 像素标记：图像上以像素边框、十字和编号定位采样点，缩放或旋转后保持与像素对齐。
- 多点平均：连续单击添加点位，在列表中选中、删除或清空；曲线与表格显示成功读取点的逐通道算术平均值。
- TXT 导出：保存当前曲线的通道序号与原始强度（单点值或多点平均值）。
- 中英文界面：跟随 Java/QuPath 运行区域设置。
- 后台读取：快速连续点击只展示最后一次请求的结果，不阻塞 JavaFX 界面。

插件显示的是原始像素强度，不受 QuPath 的 LUT、亮度或对比度设置影响。

## 安装

1. 从项目 Release 或本地构建结果中取得 `qupath-extension-spectrum-viewer-*.jar`。
2. 启动 QuPath 0.7.0，将 JAR 拖入 QuPath 主窗口并选择用户目录。
3. 重启 QuPath。
4. 打开 `Extensions > 像素光谱查看器 > 打开像素光谱查看器`。

打开窗口时会自动切换到“光谱探针”。单击工具栏中的移动工具即可恢复拖动画布；窗口中的“启用探针”按钮可再次进入取样模式。

## 像素标记、多点平均与导出

单点模式下，每次单击会替换当前采样点。主图中的橙黄色编号十字、像素边框与窗口中的 `#编号 · x/y/z/t` 对应。坐标以全分辨率图像为准，从 0 开始。

勾选“多点模式（平均光谱）”后，已有的单点会保留为第一个点。继续在图像上单击即可添加像素；重复坐标只计一次。在列表中选中一个点，其图中标记变为橙黄色，其他点为青色。使用“删除选中点”或“清空点位”修改参与计算的点。取消多点模式会保留列表中选中的点，恢复单点光谱。

平均值按每个通道独立计算：`mean[c] = sum(pixel[c]) / 已成功读取点数`。列表显示每个点的读取状态，窗口同时显示已参与计算、读取中和失败的数量；读取中或失败的点不进入分母。快速连续点击会保留所有新增点；删除后才完成的读取不会将该点加回。失败点可删除后重新添加。

切换图像、活动 viewer 或 Z/T 平面会清空选择；关闭窗口也会清除点位和临时标记。标记仅用于本扩展显示，不保存为 QuPath 标注。

点击“导出 TXT…”选择保存位置，即可导出当前显示曲线的快照。文件使用 UTF-8、制表符分隔、英文小数点，第一行为列名；数据行第一列为从 1 开始的通道序号，第二列为强度。例如：

```text
channel_index	intensity
1	12.5
2	37.0
```

无真实波长元数据时，导出使用通道序号，不将序号解释为 nm。多点模式导出当前已成功读取点的平均值；建议待“读取中”为 0 后导出完整选择。

## 样例 TIFF

本地 `data/` 中的样例是 ImageJ TIFF，维度分别为（原始 TIFF 已被 Git 忽略，不随源码上传）：

| 文件 | 维度 | 类型 |
| --- | --- | --- |
| `AF488_L445.tif` | 28 × 2048 × 2048（CYX） | uint8 |
| `AF647_L488.tif` | 23 × 2048 × 2048（CYX） | uint8 |
| `ATTO620_L514.tif` | 20 × 2048 × 2048（CYX） | uint8 |

这些文件没有真实波长元数据，因此插件使用 QuPath 通道名称，并在名称缺失时回退为 `Channel 1…N`。如果 QuPath 没有把 TIFF 识别为上述通道数，请在打开图像时明确选择 **Bio-Formats** reader。

## 构建

需要能够运行 Gradle 的 JDK；QuPath 0.7.0 官方建议 OpenJDK 25。项目自带 Gradle Wrapper，不要求全局安装 Gradle。

Windows PowerShell：

```powershell
./gradlew.bat clean test build
```

macOS/Linux：

```bash
./gradlew clean test build
```

生成的扩展 JAR 位于 `build/libs/`。QuPath、JavaFX 和日志依赖不会打入普通插件 JAR。

有图形桌面的开发环境还可以执行 `./gradlew.bat uiTest`（macOS/Linux 使用 `./gradlew uiTest`）运行真实 QuPath/JavaFX 窗口集成测试。测试使用内存偏好设置，不改变已安装 QuPath 的偏好；测试报告位于 `build/reports/tests/uiTest/`，窗口截图位于 `build/reports/spectrum-ui.png`。

## 验证像素值

可使用 Python `tifffile` 对固定坐标做独立核验：

```python
import tifffile

image = tifffile.imread("data/AF488_L445.tif")
x, y = 100, 100
print(image[:, y, x])
```

输出应与插件在 `x=100, y=100, z=0, t=0` 显示的逐通道值一致。多点平均可用 `image[:, [100, 200], [100, 200]].mean(axis=1)` 核验两个点 `(100,100)`、`(200,200)` 的结果，并逐行对照导出的 TXT。

集成验收还应检查：单点标记随缩放/旋转对齐；多点编号与列表对应；删除点立即更新均值；快速点击保留所有点；切换 Z/T 或图像后清空；关闭窗口移除标记；无数据时禁用导出；取消保存不改变光谱，保存失败在窗口内提示。

## 范围限制

- 支持离散像素的等权平均，不进行邻域或 ROI 面积平均。
- 不从文件名推断波长，也不执行光谱解混。
- 图像解码由 QuPath 的 `ImageServer`（通常为 Bio-Formats）负责。
